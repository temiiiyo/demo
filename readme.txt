# README – Интернет-магазин тканей «Швейка»

## О приложении

«Швейка» – это настольное приложение для просмотра ассортимента тканей, добавления товаров в корзину и оформления заказов.
Программа работает под управлением **Windows** и не требует установки дополнительного ПО – всё необходимое уже включено в исполняемый файл.

## Запуск

1. Скачайте и распакуйте архив с программой в любую папку.
2. Запустите файл **`shveyka.exe`**.
3. Откроется окно авторизации. Введите логин и пароль (см. ниже).
4. После входа вы попадёте в каталог товаров, где можно:
   - искать товары по названию;
   - фильтровать по категории и размеру скидки;
   - добавлять товары в корзину;
   - перейти в корзину для оформления заказа;
   - просмотреть список оформленных заказов.

## Данные для входа

В приложении предустановлены три учётные записи:

| Роль        | Логин     | Пароль |
|-------------|-----------|--------|
| Администратор | `admin`   | `123`  |
| Менеджер     | `manager` | `123`  |
| Клиент       | `client`  | `123`  |

> **Важно:** регистрация новых пользователей в текущей версии не предусмотрена. Используйте одну из указанных учётных записей.

## Возможности

### Каталог товаров
- Отображаются карточки товаров с фото, названием, ценой и скидкой (если есть).
- Поиск по названию (работает в реальном времени).
- Фильтр по категориям: «Постельные ткани», «Детские ткани».
- Фильтр по скидке: «до 10%», «до 20%», «до 30%».

### Корзина
- Добавление товаров (количество увеличивается при повторном нажатии «В корзину»).
- Просмотр списка выбранных товаров с итоговой суммой.
- Оформление заказа – после нажатия кнопки «Оформить» заказ сохраняется в базе данных.

### Заказы
- Просмотр всех оформленных заказов (номер, дата, статус, сумма).
- Удаление заказа (кнопка «Удалить» в каждой строке).

## Требования к системе

- **Операционная система:** Windows 10 / 11 (64-bit).
- **Предустановленное ПО:** не требуется (база данных и все библиотеки упакованы внутрь exe).

## Возможные проблемы

- **Не отображаются фотографии товаров** – убедитесь, что папка `images` находится в той же директории, что и `shveyka.exe`, и в ней есть файлы с именами `B111C5.JPEG`, `E112C6.JPG`, `T238C7.JPG`.
- **При запуске ничего не происходит** – попробуйте запустить файл от имени администратора или отключить антивирус временно (иногда он блокирует неизвестные exe-файлы).
- **Ошибка подключения к базе данных** – программа использует встроенную базу данных (MySQL Embedded), она запускается автоматически. Если ошибка сохраняется, перезапустите приложение.
